# The Funniest Toaster Error Message

A make.fun bounty entry. The program writes one line — the funniest error
message a kitchen toaster would show its owner — to `/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

The entry:

> Bread jammed. Escalated to management. Management is also bread.
